# UI Web Automation Framework

An end-to-end UI automation testing framework built using **Python**, **pytest**, and **Playwright**. This repository demonstrates automated browser interactions against an e-commerce web application ([SauceDemo](https://www.saucedemo.com/)).

## Test Scenarios Covered
- **Authentication:** Valid user login, URL redirection validation, and error messaging for locked-out accounts.
- **E-Commerce Checkout Flow:** Full end-to-end automated testing, including adding items to the cart, verifying badge counters, navigating checkout forms, and asserting order completions.

## Tech Stack
- **Python 3.10+**
- **Playwright** (Browser automation engine)
- **pytest & pytest-playwright** (Test runner and assertion library)
